# Amazon-ecommerce-clone

A multi-page e-commerce website built using HTML, CSS, and JavaScript
as part of my web development learning journey.

## Technologies

- HTML5
- CSS3
- JavaScript
- JavaScript Modules
- Local Storage

## Features

- Product listing
- Shopping cart
- Quantity updates
- Item deletion
- Checkout page
- Delivery-date selection

## How to Run

Clone the repository and open the project using VS Code
with Live Server.

## Project Status

Currently improving responsive design and adding further functionality.
